# Sitio: Ingenieria Multimedia

Proyecto web sencillo para la tarea sobre fundamentos de la Ingenieria Multimedia.

## Estructura

- `index.html`: contenido principal de la pagina.
- `css/styles.css`: estilos visuales, colores, distribucion y responsive.
- `js/main.js`: ventanas emergentes, botones interactivos, test y boton de regreso.
- `assets/img`: carpeta para imagenes, logos, iconos o capturas que se usen en el sitio.
- `assets/video`: carpeta para videos del sitio.
- `content`: carpeta para guardar textos de cada tema antes de pasarlos a la pagina.

## Donde guardar tus materiales

Videos:

- Guarda el video principal como `assets/video/ingenieria-multimedia/intro.mp4`.
- Si tienes mas videos, usa nombres claros como `historia.mp4`, `multimedia.mp4` o `test.mp4`.

Imagenes:

- Guarda logos, iconos o imagenes en `assets/img`.
- Usa `assets/img/ingenieria` para imagenes de la seccion Ingenieria.
- Usa `assets/img/multimedia` para imagenes de la seccion Multimedia.
- Usa `assets/img/ingenieria-multimedia` para imagenes del tema central.
- Usa `assets/img/logos` para logos de universidades, herramientas o marcas.
- Usa `assets/img/ui` para imagenes decorativas o elementos de interfaz.
- Para la imagen previa del video puedes usar `assets/img/poster-video.jpg`.

Videos:

- El video principal actual esta enlazado como `assets/video/ingenieria-multimedia/intro.mp4`.
- Usa `assets/video/ingenieria` para videos de la seccion Ingenieria.
- Usa `assets/video/multimedia` para videos de la seccion Multimedia.
- Usa `assets/video/ingenieria-multimedia` para videos del tema central.

Textos:

- Puedes guardar tus textos en archivos `.txt` dentro de `content`.
- Ejemplo: `content/ingenieria.txt`, `content/multimedia.txt`, `content/ingenieria-multimedia.txt`.

Si el archivo esta dentro de esta carpeta del proyecto, Codex puede leerlo y usarlo para actualizar la pagina.

## Como abrirlo

Abre `index.html` en el navegador.

## Como publicarlo despues

Cuando el sitio este terminado:

1. Entra a Netlify.
2. Crea una cuenta o inicia sesion.
3. Busca la opcion para desplegar manualmente un sitio.
4. Arrastra la carpeta `sitio-ing-multimedia`.
5. Copia el enlace que Netlify genera.

Ese enlace es el que se entrega para la tarea.
